# Ramadhan Alvito Alfian — Portfolio Website

A responsive, static portfolio website built with HTML, CSS, and JavaScript.

## 1. Personalize before publishing

1. Add your chosen professional portrait to `assets/` and name it `profile.jpeg` (your current filename is already correct).
2. In `index.html`, replace `YOUR_EMAIL@example.com` with the email address you want to publish.
3. Your GitHub profile link is already set to `https://github.com/rmdhnalvit`.
4. Verify internship dates, job titles, project descriptions, and publication details.
5. In the JSON-LD block, add your final website URL to the `url` field after publishing.

## 2. Preview on Windows

- Extract the ZIP file.
- Open the folder in Visual Studio Code.
- Open `index.html` in a browser, or use the VS Code Live Server extension.

## 3. Publish with GitHub Pages

1. Sign in to GitHub.
2. Create a new **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
3. Upload all files and folders from this project. `index.html` must be at the repository root.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish. Your site address will be `https://rmdhnalvit.github.io/`.

## 4. Google indexing

1. Open Google Search Console: https://search.google.com/search-console
2. Add your website URL as a URL-prefix property and complete verification.
3. Use URL Inspection to request indexing of the homepage.
4. Keep the site public and useful. Google decides whether and when it appears in Search; indexing and photo display are not guaranteed.

## Notes

- This is a static website; it does not need a database or backend.
- The profile image is not included. Use a photo you have permission to publish.
- The page uses Google Fonts. If fonts cannot load, fallback fonts are used.
